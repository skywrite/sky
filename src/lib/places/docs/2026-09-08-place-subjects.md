# Place subjects and creation at selection

Resolvable country records did not make places automatic subjects. The
extractor listed only people, organizations and projects; the web picker
listed only saved records. A substantive discussion of France could still
have no place link, and its first manual link required a separate command.

Creating countries during search or extraction would turn tentative matches
into notebook records. Selecting a country is the point at which its record
is needed. A shared catalog therefore includes saved places and unsaved
recognized countries, while creation stays behind explicit selection and
the automatic pipeline's existing relevance judgment.

A world catalog makes invented country mentions resolvable, so resolution
alone is insufficient evidence. Place subjects carry exact source quotes;
names and geographic context must occur in those quotes. Two venues named
Cafe remain two candidates until the text identifies their containing place.
Interaction scores cannot supply the missing geography.

Resumed chats previously stopped entity extraction once any rel existed.
New place subjects now append from new turns without reclassifying existing
entity relationships. Previewing archived records uses the same extraction
and selection but never materializes countries or changes rel. This keeps
the report reviewable before any historical rewrite.
