# The header keeps Organize

The day's header had grown five controls on its right: Review yesterday, Journal, New note, a paperclip
and Organize. Four styles in one row: plain text, icon and text, icon only, outlined. The paperclip had
been a labeled Add file button until New note arrived and it shrank to make room. On a laptop window with
Details open the row kept its width, the date wrapped to three lines, and Review yesterday printed over it.

Three of the five already lived where their results appear. Journal is the first line of Reflections and
New note the first line of Notes, each with a sentence saying what it is for, which a word in the header
never carried. So they left the header.

The paperclip was the import picker, not the attachments pad. A recording, transcript or document chosen
there becomes a record of the day, while the pad at the rail's foot keeps a file beside the day. The picker
moved to the Meetings heading in Details, beside that heading's other quiet link, where an imported meeting
lands. Its accessible name and hover hint stayed "Add a file" and "Add file", so nothing was renamed and the
browser tests that reach the import through it still do. Dropping a file anywhere on the day still imports it.

Review moved into the status line under the date, the way "Not started · Start" already sits there. Today's
page says "Yesterday not reviewed · Review" until yesterday's summary is saved. A past day's page says
"Not reviewed · Review", and a past day with a summary offers "Open review", which reaches the saved choices
and Review again. A review closes with the day's summary: the review store treats a day with a summary file
as done, so the line reads the same fact. The day view now carries `yesterday` for today's page, the
calendar day before the planning day with whether its summary exists, null without a day file. The return
prompt that appears on its own after time away is a different signal, idle-driven, and stays as it was.

The line follows the calendar, as the review store does: a day behind the calendar's today can be reviewed,
including the notebook's own open day before the next one starts, which is when the morning review happens.
So the open day's page, reached as Today, says "Yesterday not reviewed" about itself when the calendar has
moved on, and a future day's page offers nothing.

What is left at the right: Organize, the one control that changes this page, and the folded rail's chevron
after it, at the header's end. On a phone the date and Organize now share the row; only the summary's view
switch keeps a row of its own above the date, since it needs the width. The padding rule that squeezed five
buttons onto the row went with them.

Considered and not done: an overflow menu holding the three actions, which costs a second click for things
the page offers in one and brings a second style back; keeping Journal in the header for one-click access,
since a destination belongs in the sidebar rather than in a day's header; and routing the import picker
through the attachments pad, which would make one pad do two different things to the same file.
