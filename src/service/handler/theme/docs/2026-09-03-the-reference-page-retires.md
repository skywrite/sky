# The reference page retires

`/theme` was the concept screen the sky theme was drawn from, rebuilt in
Mantine. It showed a sample day: a morning journal, a brief, a checklist,
a record view, and a sidebar of days, horizons and topics. Every surface
was to look like it. The app grew past it. The day page, its rail, the
thread page and the explorer became the reference, and the mock still
drew a Threads list the app no longer has.

The page is gone: its route, its components, and the styles only it used.
The sidebar's state colors for thread rows went too. The rows they colored
left the sidebar earlier today. The shell HTML, the bundle on request and
the theme are unchanged.
