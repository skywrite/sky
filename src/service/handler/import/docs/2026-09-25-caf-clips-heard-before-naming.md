# CAF clips are heard before anyone names who speaks

## Before

A drop of several `.caf` clips listed them by file name, each with a
"Who's speaking?" box, and Start needed every box filled. The names
Messages gives its clips say nothing about what is in them, so the person
was naming voices blind, or playing each clip elsewhere first. A single
clip filed with `from:` set and `to:` empty; nothing asked who the message
was to, though a message always is to someone.

## Change

Each clip is heard for its opening words as it arrives, the way a voice
memo already was, and the words show under the file name ("Starts: “…”")
while the person names the speaker. A single clip gets a "To" box beside
the speaker, required before Start, and the command asks the same in the
terminal. A conversation of several clips sets `to:` to its other speakers
without asking.

## Rejected

Transcribing every clip first and asking for the speakers afterwards, with
the full text at hand. It turns Start into a question mid-run, and the
person can no longer put the clips in order before the run: order is set
in the dialog, and the run keys its retry record on that order.

## Not done

The voice-memo classifier still does not run on clips. A `.caf` from
Messages is a message; there is no kind to guess.
